## Ответы на вопросы

1. Чем статическая типизация Dart отличается от Python?

Dart проверяет тип данных на этапе компиляции, что снижает риск появления ошибки. Python же проверяет тип во время выполнения кода.

2. Что означает String?? Чем отличается от String?

String-строковый только тип данных, а String?-значит, что переменная может быть как строкой, так и null.

3. Зачем в Dart final, если в Python можно просто договориться не менять переменную?

Ключевое слово final в Dart нужно для того, чтобы переложить контроль за неизменяемостью переменных с хрупкого «человеческого фактора» на строгий автоматический контроль компилятора.

4. Чем именованный параметр {required String name} отличается от
позиционного? Приведите пример вызова.

Именнованные параметры в функциях можно заполнять в любом порядке (главное-обратиться к нему по имени), а позиционные зависят от своего порядка

Пример:

void name_age(String name, int age) {
  print('Пользователь: $name, Возраст: $age');
}

Можно вызвать только так: name_age("Макс", 18)
name_age(18, "Макс") ---> ОШИБКА

void name_age({required String name, required int age}) {
  print('Пользователь: $name, Возраст: $age');
}

В данной ситуации можно вызвать любым способом!

name_age(name="Макс", age=18) или name_age(age=18, name="Макс")
